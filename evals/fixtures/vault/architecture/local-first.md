# Arquitectura local-first

ConductLoop guarda los datos en una base SQLite dentro del Mac.
Las claves de proveedores se guardan en el llavero de macOS, nunca en el repositorio.
Nada sale del equipo salvo las llamadas al proveedor de LLM que se elija.
