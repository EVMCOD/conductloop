# Pipeline Hygiene

A weekly 30-minute pass that makes the pipeline describe reality. A stage name means nothing unless it
has an exit criterion that anyone can check.

## When to use

- Weekly, same slot, same 30 minutes, before the forecast is shared.
- Before a pricing change, a hiring decision, or a board-style number.
- When the forecast keeps slipping and nobody can say why.
- When a new rep or a new segment enters the pipeline.

Not for: individual deal coaching (that is a call review), and not for deciding which feature to build.

## Step 1 - Define the stages so each one means something

Use exactly these 5 stages for a small team. Each has one exit criterion, checked by the owner, not by
opinion.

| Stage | Means | Exit criterion to advance |
|---|---|---|
| New | a named contact at a named account who asked to hear from us | a first call is booked with a date |
| Qualified | the problem, budget and deadline are known | all 3 must-haves Yes in the qualification checklist |
| Proposal | a price and a scope are in front of the buyer | the buyer has confirmed price and scope in writing |
| Negotiation | the buyer is working the terms | a signed order form or a procurement green light |
| Won / Lost | the outcome | written reason code on Lost, handoff on Won |

Rules:

- One opportunity per row, one named owner per row. Shared opportunities are the same as unowned ones.
- No stage without a numeric deal value. A stage with no value is a forecast hole.
- The stage describes the buyer's state, not the seller's activity. "We sent a proposal" is not a stage;
  "the buyer confirmed price and scope" is.
- If two stages always happen together, merge them. If a stage has no exit criterion, it does not exist.

## Step 2 - The weekly review (30 minutes)

Same order every week, in the room with the people who own the rows.

1. **Counts and values (5 min)**: opportunities per stage, total value per stage, and pipeline coverage =
   total open value / the revenue number for the period. Coverage below 3x means the period will miss;
   above 5x usually means stage values are inflated.
2. **Stage movement (10 min)**: for each opportunity, what changed since last week. Ask "what is the next
   step, and who does it?" An opportunity with no next step moves backwards, not forwards.
3. **Stale check (5 min)**: apply the rules below. Every stale opportunity gets a date and an owner, or
   it gets closed.
4. **Forecast (5 min)**: commit = opportunities in Negotiation with a signed path; best case = everything
   with a live next step. State the number, the gap to target, and the single action that closes the gap.
5. **Wins and losses (5 min)**: each Won row gets the reason it won, each Lost row a reason code from the
   fixed list below. Read out the codes; the pattern in 5 lost deals is the actual feedback.

Reason codes for Lost, fixed list: price, no budget, no deadline, wrong segment, missing feature,
incumbent contract, decided internally, no decision, went quiet, other (with one line).

## Step 3 - The stale-opportunity rule

Staleness is measured in days since the last meaningful movement, where meaningful movement is a reply
from the buyer, a meeting, or a change of stage.

| Days since movement | Action |
|---|---|
| 0 to 13 | normal |
| 14 to 30 | flagged: needs a dated next step this week |
| 31 to 60 | last chance: send a dated close-out asking to pause or stop |
| Over 60 | close as Lost with code "went quiet" and set a 90-day no-contact |

Extra rules:

- An opportunity with a next step in the past is stale regardless of days since the last email. Fix the
  date first.
- Two consecutive weeks in the same stage with no movement means the forecast is wrong. Move it down.
- Any opportunity that has not moved for 14 days and has no meeting booked does not count in the
  forecast. It stays in the pipeline, out of the number.
- Never re-date a stale opportunity twice without a new fact. The second re-date is a lie in the
  forecast.

## Step 4 - Keep the numbers honest

- Forecast = sum of values of opportunities with a live, dated next step, weighted by stage: Qualified
  25%, Proposal 60%, Negotiation 85%. New gets no weight.
- Report committed and best case separately. One blended number is a way of avoiding a decision.
- Compare this week's forecast to last week's, and explain any drop of more than 20% by naming the
  opportunities that moved.
- A stage conversion rate below 25% between two consecutive stages, for 3 weeks in a row, is a process
  problem: fix the stage definition or the activity that should fill it.
- If 3 or more deals are lost for the same reason in a month, write it up for the product and pricing
  owner. That is not a sales problem to be trained through.

## What a good answer looks like

- The stage table with exit criteria, and the count and value per stage.
- Coverage as a multiple of the period target, with a verdict.
- A list of every stale opportunity with its days, its dated next step, and its owner; anything over 60
  days is closed.
- Commit and best case as two numbers, plus the gap and one action.
- The loss codes for the week, read out, and the pattern if there is one.

## Common traps

- Stage names that describe activity ("demoed", "followed up") instead of buyer state, which makes every
  forecast a guess.
- Leaving opportunities with no next-step date, so nothing ever goes stale and nothing gets caught.
- Re-dating instead of closing, which turns the pipeline into a graveyard of polite fictions.
- Counting a proposal as revenue because the buyer said "looks good".
- Blending commit and best case into one comfortable number.
- Reviewing the pipeline without the people who own the rows.
- Skipping the review for a week and then calling the gap "a slow quarter".
