🚀 Set up ConductLoop

What a healthy local-first second brain needs, checked live against this install. The optional ones are extras.

Checking…

🔑 Credentials — every key this app holds, and where it keeps them. Paste a key there and it goes into the keychain of your Mac; the app never shows it again.

📚 Library

Folders ConductLoop reads and indexes every hour. It never writes to them: its own notes (daily briefing, agent notes, memory export) go to the folder below.

Where the map is also written, so it travels with your notes: one file with everything, and one page per project with links your vault can follow. The agent's own workspace always gets it too.

💾 Backups

Copies of the app's database: your index, chats, agents, tasks and settings stored in the app. Taken once a day and before an update changes the database, and whenever you click below. Your notes folders are not in them: they stay where they are. The last 30 are kept.

🧠 Obsidian memory sync

Transfer the Brain's memory to your Obsidian vault as markdown — it then travels with your notes (sync, backup, git). Export writes notes; Import reads edited notes back.

🗺️ The map of your work

Your notes, ordered: which project each one belongs to, which ideas belong to nobody yet, and the projects your notes know about but the registry does not. This is what survives when you change agents.
