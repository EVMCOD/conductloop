Pair a chat

Create a code, then send it to your bot from a private chat or a group. It works once and only for 10 minutes. In a group the bot answers only commands and messages that mention it, and only from the people on that group's list (whoever sends the code is put on it).

Paired chats

Results of finished runs go to each private chat, and privately (DM) to each person on a group's list. In a group only the people on its list can talk to the agents (find a user id by having them mention the bot: they show up below to allow). A member the bot cannot message is marked unreachable — ask them to send /start to the bot.
